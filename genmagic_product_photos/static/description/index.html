GenMagic AI Product Photos

Make new product photos from the photo you already have, without leaving the product form.

What it does

Open any product, press GenMagic photos, pick a style and make a new photo of that product from its own main image. Keep the ones you like: each one is added to the product's extra media on your website, and only if you tick the box is it used as the main image instead.

  • White studio: clean white background and soft light.
  • Lifestyle scene: the product in a real-life setting.
  • With a model: a person using or wearing the product.
  • Flat lay: top-down view with props.
  • Seasonal: festive but uncluttered.

Every style asks the service to keep the product exactly as it is: same shape, colors, materials, label, logo and proportions. You can add up to 300 characters of your own wishes, choose among the image models that work from a photo, and see the cost of each photo and your balance left right after it is made.

Needs the external GenMagic service

This app is free, and it works only together with the external GenMagic service (genmagic.co). The photos are made by that service, not by Odoo. You pay GenMagic per photo from your own prepaid GenMagic balance, using your own GenMagic API key. There is no Odoo billing and no activation key. Get a key at genmagic.co/get-api-key and see prices at genmagic.co/pricing.

What data is sent, and when

  • Only when someone presses Make photo, the app sends the product's main image and the style text (plus any extra wishes typed in) to genmagic.co, together with your API key to identify your account.
  • Nothing else is sent: no customer, order, price or other product data.
  • Nothing is sent until an administrator has ticked the consent box under Settings > GenMagic. Switch it off to stop all sending.
  • The new photo is downloaded only from GenMagic's own media addresses.
  • The API key is stored as a system parameter that only administrators can read.

Set up in a minute

  1. Install the app (it needs the Website / eCommerce app).
  2. Open Settings > GenMagic, tick the consent box and paste your GenMagic API key.
  3. Open a product that has a main image and press GenMagic photos.

Make sure your server can reach genmagic.co over HTTPS. The Python package requests is required.
